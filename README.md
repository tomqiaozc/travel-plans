# travel-plans

Self-contained, interactive travel itinerary pages generated by a **Travel Planner** skill and
published via **GitHub Pages**. Each trip is a single standalone HTML file — no build step, no
backend — with an embedded map and a day-by-day plan you can reorder on the fly.

**Live:** https://tomqiaozc.github.io/travel-plans/

## Features

- **Embedded maps** — each itinerary renders its stops on an [AMap (高德)](https://amap.com) map,
  so the day's route is visible at a glance.
- **Drag-to-reorder** — plan items are sortable via [SortableJS](https://github.com/SortableJS/Sortable);
  rearrange the order of stops within a day directly in the browser.
- **Fully self-contained** — every trip is one HTML file with inline styles and scripts. Open it
  locally or serve it statically; there is nothing to install.

## How it works

Pages are produced by a Travel Planner skill and committed to this repo. A push to `main` triggers
the GitHub Pages workflow (`.github/workflows/pages.yml`), which uploads the repository root as a
static artifact and deploys it — no framework, no bundler.
